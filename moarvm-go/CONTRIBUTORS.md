## Original MoarVM Virtual Machine Project

MoarVM is a modern 64-bit virtual machine built for dynamic languages with a 6Model object system, JIT compilation, and lock-free concurrency.

- **Official Repository**: [https://github.com/MoarVM/MoarVM](https://github.com/MoarVM/MoarVM)
- **Official Website**: [https://moarvm.org](https://moarvm.org)
