=head1 NAME

raptor-wasm - C<raptor --wasm>, canvas, DOM, WebAudio

=head1 BUILD

    raptor --wasm --wasm-compiler=tinygo -o web/raptor.wasm
    raptor --wasm --wasm-compiler=go -o web/raptor.wasm
    raptor serve --port 8080

TinyGo is preferred when C<tinygo> is on PATH. Stubs
(C<raptor_bridge.js>, C<wasm_exec.js>) are written beside the
C<.wasm>. Live tour: L<https://xyzzyapps.github.io/raptor/>.

Tour B<HTTP> and B<WebGPU> lessons are disabled (they did not run
well in WASM).

=head1 WEBAUDIO

Graph in Raptor; JS wraps C<AudioNode>. Schedule on
C<audio_get_current_time> (not C<setTimeout>). Melody in the tour is
C4 E4 G4 B4 C5.

=begin code

my $ctx = audio_context_create();
my $t0 = audio_get_current_time($ctx);
my $osc = audio_create_oscillator($ctx);
my $env = audio_create_gain($ctx);
audio_set_frequency($osc, 261.63, $t0);
audio_connect($osc, $env);
audio_connect_destination($env, $ctx);
audio_osc_start($osc, $t0);

=end code

Also filter, compressor, delay, panner, analyser, LFO via
C<audio_connect_param>. C<audio_play_melody> composes that graph.
