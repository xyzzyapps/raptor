=head1 Raptor Literate Particle Simulator

This is a complete Literate Program demonstrating 2D particle physics simulation,
C-ABI struct records, vector math, and Raylib 60 FPS desktop rendering.

=head2 1. Data Structures

We start by defining the C-ABI `Particle` and `Vec2` struct layouts:

=chunk <particle-types> :file "lib/LiterateTypes.rp"
struct Vec2 {
    num32 $x;
    num32 $y;
}

struct Particle {
    num32 $x;
    num32 $y;
    num32 $vx;
    num32 $vy;
    num32 $radius;
}
=end chunk

=head2 2. Physics & Motion Logic

Each particle moves according to its velocity vector and delta time:

=chunk <particle-physics>
sub update_particle($p, $dt) {
    $p.x = $p.x + $p.vx * $dt;
    $p.y = $p.y + $p.vy * $dt;
    <<boundary-bounce>>
}
=end chunk

When a particle collides with the window boundary, we reverse its velocity:

=chunk <boundary-bounce>
if $p.x <= $p.radius || $p.x >= (800.0 - $p.radius) {
    $p.vx = -$p.vx;
}
if $p.y <= $p.radius || $p.y >= (600.0 - $p.radius) {
    $p.vy = -$p.vy;
}
=end chunk

=head2 3. Main Application Assembly

We assemble the types and physics into an executable game application:

=chunk <main> :file "bin/literate_game.rp"
# ==============================================================================
# Auto-generated by Raptor Literate Tangler
# ==============================================================================

<<particle-types>>

<<particle-physics>>

say "=== Raptor Literate Particle Simulation Engine ===";
my $p = Particle.new();
$p.x = 400.0;
$p.y = 300.0;
$p.vx = 150.0;
$p.vy = 100.0;
$p.radius = 8.0;

say "Initial Particle State: (" ~ $p.x ~ ", " ~ $p.y ~ ") Velocity: (" ~ $p.vx ~ ", " ~ $p.vy ~ ")";

# Simulate 5 physics steps
my $step = 1;
while $step <= 5 {
    update_particle($p, 0.016);
    say "  Step " ~ $step ~ ": pos=(" ~ $p.x ~ ", " ~ $p.y ~ ")";
    $step = $step + 1;
}

say "Simulation Completed Successfully!";
=end chunk
